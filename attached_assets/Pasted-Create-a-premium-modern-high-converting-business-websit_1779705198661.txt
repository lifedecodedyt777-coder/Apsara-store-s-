Create a premium, modern, high-converting business website demo for a cosmetics and personal care shop named “Apsara Store” in Shindkheda, Gujarat, India.

The website must feel like a real brand launch, not a college project and not a generic template. It should look expensive, clean, cool, trustworthy, and visually memorable. The design must be distinct from ordinary small business websites.

Business context:
- Brand name: Apsara Store
- Category: Beauty, cosmetics, personal care, skincare, haircare, grooming, fragrance, and beauty accessories
- Location: Shindkheda, Gujarat, India
- Contact: use the visible phone number from the provided profile screenshot
- Audience: local customers, beauty shoppers, women and men looking for cosmetics, self-care, grooming, and trusted product guidance
- Tone: premium, friendly, elegant, local, confident

Design direction:
- Style: luxury editorial + modern retail + subtle glassmorphism
- Mood: clean, premium, polished, minimal, sharp
- Avoid: childish colors, clutter, generic stock-business layout, loud gradients, cheap-looking card designs, and crowded sections
- Use strong typography, generous whitespace, soft shadows, rounded corners, elegant spacing, and subtle motion
- Use a refined palette: black, ivory, warm beige, blush, muted rose, and a small gold accent
- Make it feel like a premium beauty brand with local trust
- Mobile-first, fast, responsive, accessible, and conversion-focused

Technical direction:
- Build as a modern responsive website using a clean component-based architecture
- If code is generated, use Next.js + React + Tailwind CSS + Framer Motion + shadcn/ui + Lucide icons
- Use SEO-friendly structure, semantic HTML, performance optimization, and image lazy-loading
- Make the site easy to extend later into a real store website with products, categories, and offers

3. Best sellers / trending products section

4. Why Apsara Store section
